# FEATURE-task-stop

> 更新日期：2025-12-30 | 关联：[MAIN-PRD](../MAIN-PRD.md)

## 解决什么问题？

用户需要在 Claude 执行方向错误或耗时过长时，立即中断任务。这可以节省时间和 token 消耗，避免错误操作造成更大影响。

## 用户故事

| 故事 | 验收标准 | 优先级 |
|------|----------|--------|
| 作为用户，我想随时停止正在执行的任务 | 点击停止按钮后 Claude 立即停止输出 | P0 |
| 作为用户，我想知道任务已被停止 | 显示"任务已停止"提示 | P0 |

## 核心流程

```
任务执行中（status = running）
    |
    v
用户点击停止按钮
    |
    v
发送 session.stop { sessionId }
    |
    v
+---------------------+
| 显示"任务已停止"     |
+---------------------+
    |
    v
恢复输入框可用
```

## 业务规则

| 规则 | 说明 |
|------|------|
| 停止按钮可见性 | 仅在 status = running 时显示 |
| 停止机制 | 服务端向 Claude Code 进程发送 SIGINT |
| 停止后状态 | 会话变为 idle，可继续发送新消息 |
