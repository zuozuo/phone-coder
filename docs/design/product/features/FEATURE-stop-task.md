## 1. 功能概述

### 1.1 背景

Claude Code 执行某些任务可能需要较长时间，或者用户发现 AI 走错了方向，需要能够远程中断当前正在执行的任务。

### 1.2 目标

提供一键停止当前任务的能力，相当于在终端按 Ctrl+C。

### 1.3 范围

**包含**：
- 停止当前运行中的任务
- 停止状态反馈

**不包含**：
- 部分停止（只停止某个子任务）
- 暂停/恢复

### 3.1 页面清单

### 3.2 交互流程

```
+------------------+
|  用户点击停止    |
+------------------+
        |
        v
+------------------+     是      +------------------+

+------------------+             +------------------+
        | 否                            |
        v                               v
+------------------+            +------------------+
|  按钮置灰/隐藏   |            |  显示"停止中..."  |
+------------------+            +------------------+
                                        |
                                        v
                               +------------------+
                               |  收到停止确认    |
                               +------------------+
                                        |
                                        v
                               +------------------+
                               |  更新状态为 idle |
                               +------------------+
```

### 3.3 界面线框图

```
运行中状态：
+------------------------------------------+
|  < 返回       项目名称            ⏹ 停止  |  <- 停止按钮可点击
+------------------------------------------+

停止中状态：
+------------------------------------------+

+------------------------------------------+
```

### 3.4 关键交互说明

**交互点1**：停止任务
- 触发方式：点击停止按钮
- 反馈形式：按钮变为"停止中..."，禁用点击
- 特殊说明：停止完成后按钮隐藏，状态变为 idle

## 4. 详细设计

### 4.1 业务规则

1. **按钮可见性**：只在 running 状态显示停止按钮
2. **防重复点击**：发送停止请求后禁用按钮
3. **停止机制**：Server 向 Claude Code 进程发送 SIGINT 信号

### 4.2 接口描述

#### 接口1：session.stop（客户端 → Server）

**功能说明**：停止当前运行的任务

**输入**：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| type | String | 是 | 固定为 "session.stop" |
| sessionId | String | 是 | 会话 ID |

**输出**：

| 字段 | 类型 | 说明 |
|------|------|------|
| type | String | 固定为 "session.stopped" |
| sessionId | String | 会话 ID |

**错误处理**：

| 错误场景 | 错误码 | 用户提示 |
|----------|--------|----------|
| 会话不存在 | SESSION_NOT_FOUND | "会话不存在" |
| 任务未在运行 | NOT_RUNNING | "当前没有运行中的任务" |
