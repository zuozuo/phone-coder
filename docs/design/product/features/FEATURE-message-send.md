# FEATURE-message-send

> 更新日期：2025-12-30 | 关联：[MAIN-PRD](../MAIN-PRD.md)

## 解决什么问题？

用户需要在手机上向 Claude Code 发送编程指令。这是 Phone Coder 的核心交互功能，让用户能够远程下达编程任务。

## 用户故事

| 故事 | 验收标准 | 优先级 |
|------|----------|--------|
| 作为用户，我想在输入框输入指令并发送 | 点击发送后消息显示在聊天界面，并触发 Claude 响应 | P0 |
| 作为用户，我想看到自己发送的消息 | 消息以用户气泡样式显示 | P0 |

## 核心流程

```
用户输入文本
    |
    v
点击发送按钮
    |
    v
发送 message.send { sessionId, content }
    |
    v
+------------------+     失败     +------------------+
| 显示用户消息气泡  | ----------> | 显示发送失败提示  |
+------------------+             | 允许重试         |
    | 成功                        +------------------+
    v
等待 stream 响应...
```

## 业务规则

| 规则 | 说明 |
|------|------|
| 发送时机 | 点击发送按钮或按回车键（Shift+Enter 换行） |
| 空消息 | 不允许发送空消息 |
| 发送中状态 | 发送后禁用输入框，直到收到 message.done |
| 发送失败 | 显示错误提示，消息标记为"发送失败"，允许点击重试 |
