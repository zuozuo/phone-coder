# FEATURE-session-management

> 更新日期：2025-12-30 | 关联：[MAIN-PRD](../MAIN-PRD.md)

## 解决什么问题？

用户需要在手机上管理多个项目的编程会话，包括查看会话列表、创建新会话、切换项目。这是使用 Phone Coder 的入口功能。

## 用户故事

| 故事 | 验收标准 | 优先级 |
|------|----------|--------|
| 作为用户，我想查看所有会话列表，以便了解当前项目状态 | 显示会话列表，包含项目名、状态（idle/running） | P0 |
| 作为用户，我想创建新会话，以便开始新项目的编程任务 | 选择预设目录后成功创建会话 | P0 |
| 作为用户，我想点击会话进入聊天页，以便继续编程 | 点击后跳转到对应会话的聊天界面 | P0 |

## 核心流程

```
首页加载
    |
    v
发送 session.list 请求
    |
    v
+---------------+
| 显示会话列表   |  ← 每项显示：项目名 + 状态
+---------------+
    |
    +---> [点击会话] ---> 进入聊天页
    |
    +---> [新建会话] ---> 选择预设目录 ---> 发送 session.create ---> 进入聊天页
```

## 业务规则

| 规则 | 说明 |
|------|------|
| 预设目录 | 从 config.yaml 的 workdirs 列表读取，不支持手动输入 |
| 会话状态 | idle（空闲）、running（执行中） |
| 会话持久化 | 会话信息存储在服务端 SQLite，客户端不缓存 |
