## 1. 功能概述

### 1.1 背景

开发者通常同时在多个项目上工作，需要能够管理多个 Claude Code 会话，每个会话对应不同的项目目录。

### 1.2 目标

提供完整的会话管理能力：
- 查看所有会话列表
- 创建新会话（指定工作目录）
- 切换会话
- 关闭会话

### 1.3 范围

**包含**：
- 会话列表展示
- 创建新会话
- 切换会话
- 删除/关闭会话
- 会话状态显示

**不包含**：
- 会话内容搜索
- 会话导出

## 4. 详细设计

### 4.1 业务规则

1. **会话排序**：按最近使用时间倒序，running 状态置顶
2. **状态显示**：running（绿点）、idle（灰点）、stopped（红点）
3. **删除规则**：删除会话同时关闭 Claude Code 进程
4. **预设目录**：从 Server config.yaml 读取 workdirs 列表

### 4.2 接口描述

#### 接口1：session.list（客户端 → Server）

**功能说明**：获取所有会话列表

**输入**：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| type | String | 是 | 固定为 "session.list" |

**输出**：

| 字段 | 类型 | 说明 |
|------|------|------|
| type | String | 固定为 "session.list" |
| sessions | Array | 会话列表 |
| sessions[].id | String | 会话 ID |
| sessions[].workDir | String | 工作目录 |
| sessions[].status | String | 状态：running/idle/stopped |
| sessions[].updatedAt | String | 最后更新时间 |

#### 接口2：session.create（客户端 → Server）

**功能说明**：创建新会话

**输入**：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| type | String | 是 | 固定为 "session.create" |
| workDir | String | 是 | 工作目录路径 |

**输出**：

| 字段 | 类型 | 说明 |
|------|------|------|
| type | String | 固定为 "session.created" |
| sessionId | String | 新会话 ID |
| workDir | String | 工作目录 |

**错误处理**：

| 错误场景 | 错误码 | 用户提示 |
|----------|--------|----------|
| 目录不存在 | DIR_NOT_FOUND | "目录不存在" |
| 权限不足 | PERMISSION_DENIED | "无权限访问该目录" |

#### 接口3：session.delete（客户端 → Server）

**功能说明**：删除会话

**输入**：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| type | String | 是 | 固定为 "session.delete" |
| sessionId | String | 是 | 会话 ID |

### 4.3 状态流转

**会话状态**：

| 状态值 | 状态名称 | 说明 |
|--------|----------|------|
| running | 运行中 | Claude Code 正在执行任务 |
| idle | 空闲 | Claude Code 等待输入 |
| stopped | 已停止 | 会话已关闭 |

## 5. 验收标准

| 场景 | 前置条件 | 操作步骤 | 预期结果 |
|------|----------|----------|----------|
| 查看列表 | 有历史会话 | 1. 打开 App | 显示所有会话，按时间排序 |
| 创建会话 | 已连接 Server | 1. 点击新建 2. 选择目录 3. 确认 | 创建成功，进入聊天页 |
| 删除会话 | 有会话存在 | 1. 左滑会话 2. 点击删除 3. 确认 | 会话从列表消失 |
| 切换会话 | 有多个会话 | 1. 返回首页 2. 点击另一会话 | 进入对应聊天页 |
