## 1. 功能概述

### 1.1 背景

在与 Claude Code 交互时，有些指令经常使用（如"继续"、"取消"、"/help"），每次手动输入效率低。

### 1.2 目标

提供快捷指令按钮，一键发送常用命令。

### 1.3 范围

**包含**：
- 预设快捷指令
- 一键发送
- 自定义快捷指令（V2）

**不包含**：
- 指令参数输入
- 指令组合/宏

## 3. 交互设计

### 3.1 页面清单

| 页面 | 入口 | 功能说明 |
|------|------|----------|
| 聊天页（快捷指令栏） | 输入区上方 | 显示快捷指令按钮 |

### 3.2 交互流程

```
+------------------+
|  点击快捷指令    |
+------------------+
        |
        v
+------------------+
|  发送对应文本    |
+------------------+
        |
        v
+------------------+
|  等待 Claude 响应 |
+------------------+
```

### 3.3 界面线框图

```
+------------------------------------------+
|                                          |
|            (消息列表区域)                 |
|                                          |
+------------------------------------------+
|  [继续] [取消] [/help] [/status] [更多▼] |  <- 快捷指令栏
+------------------------------------------+
|  +----------------------------+  🎤  ➤  |
|  |  输入消息...               |         |
|  +----------------------------+         |
+------------------------------------------+

点击"更多"展开：
+------------------------------------------+
|  [继续] [取消] [/help] [/status] [更多▲] |
+------------------------------------------+
|  [/compact] [/cost] [/clear] [/doctor]  |
+------------------------------------------+
|  +----------------------------+  🎤  ➤  |
+------------------------------------------+
```

### 3.4 关键交互说明

**交互点1**：点击快捷指令
- 触发方式：点击按钮
- 反馈形式：直接发送对应文本
- 特殊说明：不需要确认，立即发送

**交互点2**：展开更多
- 触发方式：点击"更多"按钮
- 反馈形式：展开第二行快捷指令
- 特殊说明：再次点击收起

## 4. 详细设计

### 4.1 业务规则

1. **默认指令**：
   - 第一行（常用）：继续、取消、/help、/status
   - 第二行（更多）：/compact、/cost、/clear、/doctor

2. **发送行为**：点击即发送，等同于输入文本后点击发送

3. **状态限制**：会话空闲时才能发送

### 4.2 快捷指令列表

| 按钮 | 发送内容 | 说明 |
|------|----------|------|
| 继续 | 继续 | 让 Claude 继续之前的任务 |
| 取消 | 取消 | 取消当前操作 |
| /help | /help | 显示帮助信息 |
| /status | /status | 显示当前状态 |
| /compact | /compact | 压缩对话历史 |
| /cost | /cost | 显示 token 消耗 |
| /clear | /clear | 清空对话历史 |
| /doctor | /doctor | 诊断问题 |
