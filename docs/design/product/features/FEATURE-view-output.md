## 1. 功能概述

### 1.1 背景

开发者使用 Claude Code 执行任务时，经常需要等待较长时间才能看到结果。当需要离开电脑时，无法在移动端查看 CLI 的实时输出，只能等回到电脑前才能知道任务进展。

### 1.2 目标

让用户能在手机上实时查看 Claude Code 的输出内容，包括：
- 流式输出（AI 正在生成的内容）
- 历史消息（之前的对话记录）
- Markdown 渲染（代码高亮、格式化）

### 1.3 范围

**包含**：
- 实时接收并显示 Claude Code 输出
- Markdown 渲染和代码高亮
- 查看历史消息记录
- 自动滚动到最新内容

**不包含**：
- 发送消息（F-002）
- 多会话切换（F-003）
- 文件预览/下载

## 4. 详细设计

### 4.1 业务规则

| 规则 | 说明 |
|------|------|
| 连接建立 | 进入聊天页时自动建立 WebSocket 连接，连接失败显示重试按钮 |
| 消息渲染 | 使用 Markdown 渲染库处理内容，代码块使用 highlight.js 高亮 |
| 自动滚动 | 新消息到达时自动滚动到底部，用户手动上滑超过 100px 时暂停自动滚动 |
| 历史加载 | 进入会话时请求历史消息，按时间正序显示 |
| 断线处理 | WebSocket 断开时显示"连接已断开"提示，支持手动重连 |

### 4.2 接口描述

#### 接口1：message.stream（Server → 客户端）

**功能说明**：推送 Claude Code 的流式输出

**消息格式**：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| type | String | 是 | 固定为 "message.stream" |
| sessionId | String | 是 | 会话 ID |
| content | String | 是 | 本次输出的内容片段 |

**示例**：
```json
{
  "type": "message.stream",
  "sessionId": "sess_123",
  "content": "好的，我来帮你"
}
```

#### 接口2：message.done（Server → 客户端）

**功能说明**：通知客户端消息输出完成

**消息格式**：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| type | String | 是 | 固定为 "message.done" |
| sessionId | String | 是 | 会话 ID |

#### 接口3：message.error（Server → 客户端）

**功能说明**：通知客户端发生错误

**消息格式**：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| type | String | 是 | 固定为 "message.error" |
| sessionId | String | 是 | 会话 ID |
| code | String | 是 | 错误码 |
| message | String | 是 | 错误描述 |

**错误码定义**：

| 错误码 | 说明 | 用户提示 |
|--------|------|----------|
| CONN_LOST | WebSocket 断开 | "连接已断开，点击重试" |
| SESSION_NOT_FOUND | 会话不存在 | "会话不存在或已关闭" |
| CLI_ERROR | Claude Code 执行错误 | "执行出错：{message}" |

### 4.3 状态流转

**消息状态定义**：

| 状态值 | 状态名称 | 说明 |
|--------|----------|------|
| streaming | 流式输出中 | 正在接收内容 |
| done | 完成 | 内容接收完毕 |
| error | 错误 | 接收失败 |

**状态流转图**：

```
+------------+   收到 stream   +------------+   收到 done   +------------+
|   (初始)   | -------------> | streaming  | ------------> |    done    |
+------------+                +------------+               +------------+
                                    |
                                    | 连接断开/收到 error
                                    v
                              +------------+
                              |   error    |
                              +------------+
```

## 5. 验收标准

| 场景 | 前置条件 | 操作步骤 | 预期结果 |
|------|----------|----------|----------|
| 正常查看输出 | 已连接 Server，会话运行中 | 1. 打开会话 | Claude 输出实时显示，延迟 < 500ms |
| 代码高亮 | Claude 输出包含代码块 | 1. 查看消息 | 代码有语法高亮，等宽字体 |
| 查看历史 | 会话有历史消息 | 1. 重新打开会话 | 显示之前的对话记录 |
| 自动滚动 | 消息列表已滚动到底部 | 1. 等待新消息 | 自动滚动到最新内容 |
| 暂停滚动 | 消息正在输出中 | 1. 手动向上滚动 | 停止自动滚动 |
| 断线重连 | 网络断开后恢复 | 1. 等待网络恢复 | 显示断线提示，支持重连 |

## 6. 风险与依赖

### 6.1 依赖项

| 依赖内容 | 负责方 | 状态 | 降级方案 |
|----------|--------|------|----------|
| Go Server WebSocket 服务 | 后端 | 待开发 | - |

### 6.2 风险评估

| 风险描述 | 概率 | 影响 | 缓解措施 |
|----------|------|------|----------|
| 网络不稳定导致断连 | 高 | 中 | 自动重连 + 断线提示 |
| 大量输出导致渲染卡顿 | 中 | 中 | 虚拟列表 + 分批渲染 |
| Markdown 解析错误 | 低 | 低 | 降级为纯文本显示 |
