# FEATURE-stream-output

> 更新日期：2025-12-30 | 关联：[MAIN-PRD](../MAIN-PRD.md)

## 解决什么问题？

用户需要实时看到 Claude Code 的回复，而不是等待全部完成后才显示。流式输出让用户能够及时了解任务执行进度，提升交互体验。

## 用户故事

| 故事 | 验收标准 | 优先级 |
|------|----------|--------|
| 作为用户，我想实时看到 Claude 的输出 | 收到 message.stream 后立即追加显示 | P0 |
| 作为用户，我想看到格式化的代码 | Markdown 渲染 + 代码高亮 | P0 |
| 作为用户，我想知道输出何时结束 | 收到 message.done 后显示完成状态 | P0 |

## 核心流程

```
收到 WebSocket 事件
    |
    +---> [message.stream] ---> 追加内容到 AI 气泡（实时渲染 Markdown）
    |
    +---> [message.done] ---> 解除发送禁用状态
    |
    +---> [message.error] ---> 显示错误信息 ---> 解除发送禁用状态
```

## 业务规则

| 规则 | 说明 |
|------|------|
| 渲染方式 | 使用 Markdown 渲染，代码块高亮 |
| 自动滚动 | 新内容到达时自动滚动到底部；用户手动向上滚动时暂停自动滚动 |
| 断线处理 | WebSocket 断开时显示"连接已断开"提示 |
| 错误处理 | 收到 message.error 时，以红色样式显示错误信息 |
