# FEATURE-password-auth

> 更新日期：2025-12-30 | 关联：[MAIN-PRD](../MAIN-PRD.md)

## 解决什么问题？

用户需要保护本地开发环境，防止未授权访问。通过密码认证确保只有合法用户才能远程操控开发机上的 Claude Code。

## 用户故事

| 故事 | 验收标准 | 优先级 |
|------|----------|--------|
| 作为用户，我想在连接时输入密码验证身份 | 密码正确后进入首页，错误则提示重试 | P0 |
| 作为用户，我想保存密码避免重复输入 | 密码保存在本地，下次自动填充 | P1 |

## 核心流程

```
App 启动
    |
    v
建立 WebSocket 连接
    |
    v
发送 auth { password }
    |
    v
+-------------------+     失败     +-------------------+
| auth.result       | ----------> | 显示错误，重试     |
| success = true    |             +-------------------+
+-------------------+
    | 成功
    v
进入首页（会话列表）
```

## 业务规则

| 规则 | 说明 |
|------|------|
| 密码存储 | 服务端：config.yaml；客户端：本地存储（可选保存） |
| 认证时机 | 每次 WebSocket 连接建立后立即认证 |
| 失败处理 | 显示错误信息，允许重新输入 |
| 会话有效期 | 连接断开后需重新认证 |
