## 1. 功能概述

### 1.1 背景

用户在手机上查看 Claude Code 输出后，需要能够继续与 AI 交互，发送新的指令或问题，实现完整的移动办公体验。

### 1.2 目标

让用户能在手机上向 Claude Code 发送消息，支持：
- 文本输入
- 语音输入转文字
- 快捷指令

### 1.3 范围

**包含**：
- 文本消息发送
- 语音输入转文字
- 快捷指令按钮
- 发送状态反馈

**不包含**：
- 文件上传
- 图片发送

### 3.4 关键交互说明

**交互点1**：文本发送
- 触发方式：点击发送按钮或键盘回车
- 反馈形式：消息立即显示在列表中，状态为"发送中"
- 特殊说明：发送后清空输入框，自动滚动到底部

**交互点2**：语音输入
- 触发方式：点击麦克风按钮
- 反馈形式：显示录音界面，实时显示录音时长
- 特殊说明：录音完成后自动转文字填入输入框，用户确认后发送

**交互点3**：快捷指令
- 触发方式：点击快捷按钮
- 反馈形式：直接发送对应指令
- 特殊说明：可配置常用指令列表

## 4. 详细设计

### 4.1 业务规则

1. **发送限制**：输入框为空时禁用发送按钮
2. **防重复发送**：发送中状态时禁用发送按钮，防止重复提交
3. **语音时长**：语音录制最长 60 秒
4. **快捷指令**：默认提供 [继续]、[取消]、[/help]、[/status]

### 4.2 接口描述

#### 接口1：message.send（客户端 → Server）

**功能说明**：发送用户消息到 Claude Code

**输入**：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| type | String | 是 | 固定为 "message.send" |
| sessionId | String | 是 | 会话 ID |
| content | String | 是 | 消息内容 |

**错误处理**：

| 错误场景 | 错误码 | 用户提示 |
|----------|--------|----------|
| 会话不存在 | SESSION_NOT_FOUND | "会话不存在或已关闭" |
| Claude 正在运行 | CLI_BUSY | "请等待当前任务完成" |
| 连接断开 | CONN_LOST | "连接已断开，请重试" |

### 4.3 状态流转

**消息发送状态**：

| 状态值 | 状态名称 | 说明 |
|--------|----------|------|
| sending | 发送中 | 消息已发出，等待确认 |
| sent | 已发送 | Server 已收到 |
| failed | 发送失败 | 发送出错 |
