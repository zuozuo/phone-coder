## 1. 功能概述

### 1.1 背景

用户在手机上查看 Claude Code 输出后，需要能够继续与 AI 交互，发送新的指令或问题，实现完整的移动办公体验。

### 1.2 目标

让用户能在手机上向 Claude Code 发送消息，这是 Phone Coder 的核心交互功能，让用户能够远程下达编程任务。

### 1.3 范围

**包含**：
- 文本消息发送
- 发送状态反馈
- 发送失败重试

**不包含**：
- 文件上传
- 图片发送
- 语音输入（F-006）
- 快捷指令（F-007）

                                        |

                               |                 |

                               |                 |
                               v                 v
                       +-------------+   +------------------+
                       | 显示用户消息|   | 显示发送失败提示  |

### 3.4 关键交互说明

**交互点1**：文本发送
- 触发方式：点击发送按钮或键盘回车（Shift+Enter 换行）
- 反馈形式：消息立即显示在列表中，状态为"发送中"
- 特殊说明：发送后清空输入框，自动滚动到底部

**交互点2**：发送状态
- 触发方式：发送消息后
- 反馈形式：显示"发送中" → "已发送" 或 "发送失败"
- 特殊说明：发送中时禁用输入框和发送按钮

**交互点3**：重试发送
- 触发方式：点击"重试"按钮
- 反馈形式：重新发送消息
- 特殊说明：保留原消息内容

## 4. 详细设计

### 4.1 业务规则

| 规则 | 说明 |
|------|------|
| 发送时机 | 点击发送按钮或按回车键（Shift+Enter 换行） |
| 空消息 | 不允许发送空消息，发送按钮置灰 |
| 发送中状态 | 发送后禁用输入框，直到收到 message.done 或 message.error |
| 发送失败 | 显示错误提示，消息标记为"发送失败"，允许点击重试 |
| 会话状态 | 当会话状态为 running 时，提示"请等待当前任务完成" |

### 4.2 接口描述

#### 接口1：message.send（客户端 → Server）

**功能说明**：发送用户消息到 Claude Code

**请求格式**：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| type | String | 是 | 固定为 "message.send" |
| sessionId | String | 是 | 会话 ID |
| content | String | 是 | 消息内容 |
| messageId | String | 是 | 客户端生成的消息 ID，用于关联响应 |

**示例**：
```json
{
  "type": "message.send",
  "sessionId": "sess_123",
  "content": "帮我检查这个函数的错误",
  "messageId": "msg_456"
}
```

#### 接口2：message.sent（Server → 客户端）

**功能说明**：确认消息已收到

**响应格式**：

| 字段 | 类型 | 说明 |
|------|------|------|
| type | String | 固定为 "message.sent" |
| sessionId | String | 会话 ID |
| messageId | String | 客户端消息 ID |

#### 接口3：message.error（Server → 客户端）

**功能说明**：消息发送失败

**响应格式**：

| 字段 | 类型 | 说明 |
|------|------|------|
| type | String | 固定为 "message.error" |
| sessionId | String | 会话 ID |
| messageId | String | 客户端消息 ID |
| code | String | 错误码 |
| message | String | 错误描述 |

**错误码定义**：

| 错误码 | 说明 | 用户提示 |
|--------|------|----------|
| SESSION_NOT_FOUND | 会话不存在 | "会话不存在或已关闭" |
| CLI_BUSY | Claude 正在运行 | "请等待当前任务完成" |
| CONN_LOST | 连接断开 | "连接已断开，请重试" |
| INVALID_CONTENT | 消息内容无效 | "消息内容无效" |

### 4.3 状态流转

**消息发送状态**：

| 状态值 | 状态名称 | 说明 |
|--------|----------|------|
| sending | 发送中 | 消息已发出，等待确认 |
| sent | 已发送 | Server 已收到 |
| failed | 发送失败 | 发送出错 |

**状态流转图**：

```
+------------+   发送请求   +------------+   收到 sent   +------------+
|   (初始)   | -----------> |  sending   | ------------> |    sent    |
+------------+              +------------+               +------------+
                                  |
                                  | 超时/收到 error
                                  v
                            +------------+   点击重试   +------------+
                            |   failed   | -----------> |  sending   |
                            +------------+              +------------+
```

## 5. 验收标准

| 场景 | 前置条件 | 操作步骤 | 预期结果 |
|------|----------|----------|----------|
| 正常发送 | 已连接，会话空闲 | 1. 输入文字 2. 点击发送 | 消息显示在列表，Claude 开始响应 |
| 空消息 | 输入框为空 | 1. 点击发送按钮 | 按钮置灰，无法点击 |
| 发送中状态 | 消息正在发送 | 1. 观察界面 | 显示"发送中"，输入框禁用 |
| 发送失败 | 网络断开 | 1. 发送消息 | 显示发送失败，提供重试按钮 |
| 重试发送 | 消息发送失败 | 1. 点击重试 | 重新发送消息 |
| 会话忙碌 | Claude 正在执行任务 | 1. 发送消息 | 提示"请等待当前任务完成" |
