# Phone Coder - Main PRD

> 更新日期：2025-12-30 | 作者：Claude

## 我们要解决什么问题？

程序员在离开电脑时无法继续编程任务。当出现紧急 bug 或需要快速迭代时，只能等到回到工位才能处理。Phone Coder 让程序员可以在手机上远程操控电脑上的 Claude Code，实现真正的移动编程。

## 为谁解决？

### 目标用户画像

- **主要用户**：需要 on-call 响应的后端/全栈程序员
- **使用场景**：通勤途中、休息时接到紧急修复需求
- **技术背景**：熟悉 CLI 工具，有使用 Claude Code 经验
- **设备环境**：Mac 开发机 + iPhone/Android 手机

### 用户痛点

| 痛点 | 严重程度 | 现有解决方案的不足 |
|------|----------|-------------------|
| 离开工位无法处理紧急 bug | 高 | SSH 操作体验差，无 AI 辅助 |
| 手机打字效率低 | 中 | 语音输入可缓解 |

## 如何验证成功？

| 类型 | 指标 | 目标 | 衡量方式 |
|------|------|------|----------|
| 技术 | 消息发送成功率 | > 99% | 服务端日志统计 |
| 技术 | 端到端延迟 | < 2s | 客户端埋点 |
| 业务 | 周活跃用户 | MVP: 自己使用 | 暂无 |
| 业务 | 移动端任务完成率 | > 80% | 通过手机发起并成功完成的编程任务占比 |

## 产品架构

```
┌─────────────────┐     HTTPS/WSS      ┌─────────────────┐
│   Ionic App     │ ←───────────────→  │   Go Server     │
│   (手机端)       │   Cloudflare       │   (本地 Mac)     │
│                 │     Tunnel         │                 │
│  - 密码认证     │                    │  - 密码校验     │
│  - WebSocket    │                    │  - 进程管理     │
└─────────────────┘                    └────────┬────────┘
                                               │ stdin/stdout
                                      ┌────────┴────────┐
                                      │   Claude Code   │
                                      │   (子进程)       │
                                      └─────────────────┘
```

**数据流说明**：
1. 手机端通过 Cloudflare Tunnel 建立 WSS 连接
2. 认证通过后，指令通过 WebSocket 发送到 Go Server
3. Go Server 将指令写入 Claude Code stdin
4. Claude Code stdout 通过 WebSocket 流式推送到手机端

## 核心功能

| 功能 | 用户故事 | 解决什么问题 | 优先级 |
|------|----------|-------------|--------|
| 会话管理 | 作为用户，我想查看和切换不同项目的会话 | 在手机上管理多个项目的编程任务 | P0 |
| 消息发送 | 作为用户，我想向 Claude Code 发送指令 | 远程下达编程任务 | P0 |
| 流式输出 | 作为用户，我想实时看到 Claude 的回复 | 及时了解任务执行进度和结果 | P0 |
| 任务停止 | 作为用户，我想随时停止 Claude 的执行 | 当执行方向错误或占用过多资源时，立即中断以节省时间和 token | P0 |
| 密码认证 | 作为用户，我想保护我的开发环境 | 防止未授权访问本地开发机 | P0 |
| 语音输入 | 作为用户，我想用语音输入指令 | 手机打字效率低，语音更快捷 | P1 |
| 快捷指令 | 作为用户，我想一键发送常用命令 | 快速执行"继续"、"取消"等高频操作 | P1 |

## 非功能性需求

| 类型 | 要求 |
|------|------|
| 安全性 | 所有通信必须加密（HTTPS/WSS） |
| 隐私 | 代码内容不经过第三方服务器存储 |
| 可用性 | 服务中断时客户端应有明确提示 |
| 兼容性 | iOS 15+, Android 10+ |
