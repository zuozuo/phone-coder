# ADR-0004: 认证方案选型

## 状态

已采纳 | 2025-12-30

## 背景

Phone Coder 允许用户通过手机远程操控本地开发机上的 Claude Code，涉及代码执行权限，必须有认证机制防止未授权访问。

需求：
- 保护开发环境不被未授权访问
- 认证过程简单（个人使用）
- 支持记住密码，避免重复输入

约束条件：
- MVP 阶段，单用户场景
- 已有 Cloudflare Tunnel 提供 HTTPS 加密
- 尽量简化，快速实现

## 决策

采用 **WebSocket + 密码认证** 方案：
- 连接建立后首先发送密码认证
- 密码存储在服务端 config.yaml
- 客户端可选择记住密码（使用设备安全存储）

## 备选方案

| 方案 | 优点 | 缺点 |
|------|------|------|
| **密码认证** | 实现简单<br>无需外部依赖<br>适合单用户 | 安全性一般<br>无自动过期 |
| **JWT Token** | 无状态<br>可设置过期时间<br>可扩展 | 实现复杂<br>需要刷新机制<br>MVP 过度设计 |
| **OAuth2** | 标准协议<br>可对接第三方 | 实现复杂<br>需要额外服务<br>单用户不必要 |
| **API Key** | 实现简单<br>无状态 | 泄露风险<br>无法撤销 |

## 决策理由

1. **简单直接**：MVP 阶段个人使用，密码认证足够
2. **无外部依赖**：不需要额外的认证服务或数据库
3. **安全足够**：
   - Cloudflare Tunnel 已提供传输层加密（HTTPS/WSS）
   - 密码不在网络明文传输（WebSocket 已加密）
   - 客户端使用设备安全存储（iOS Keychain / Android Keystore）
4. **用户体验**：支持记住密码，不需要每次输入
5. **可演进**：后续可以平滑升级到 JWT Token 方案

## 认证流程

```
+----------+                    +----------+
|  Client  |                    |  Server  |
+----------+                    +----------+
     |                               |
     | 1. 建立 WSS 连接              |
     |------------------------------>|
     |                               |
     | 2. 发送 auth 消息             |
     | { type: "auth",               |
     |   password: "xxx" }           |
     |------------------------------>|
     |                               |
     |                    3. 校验密码 |
     |                               |
     | 4. 返回 auth.result           |
     | { type: "auth.result",        |
     |   success: true/false }       |
     |<------------------------------|
     |                               |
     | (认证成功后可发送其他消息)     |
     |                               |
+----------+                    +----------+
```

## 安全措施

| 措施 | 说明 |
|------|------|
| 传输加密 | Cloudflare Tunnel 提供 TLS |
| 密码存储 | 服务端 config.yaml（建议 bcrypt，v0.2 实现）|
| 客户端存储 | iOS Keychain / Android Keystore |
| 认证时机 | 每次 WebSocket 连接都需要认证 |

## 后续演进（v0.2）

1. 密码使用 bcrypt 哈希存储
2. 添加失败次数限制和延迟
3. 可选升级到 JWT Token（支持多设备）
4. 可选添加双因素认证

## 影响

### 正面影响

- 实现简单，快速上线 MVP
- 用户体验好（记住密码）
- 无需额外服务依赖

### 负面影响

- 密码明文存储在 config.yaml（v0.2 改进）
- 无防暴力破解机制（v0.2 添加）
