## 1. 项目概述

### 1.1 背景

Phone Coder 是一款让程序员在手机上远程操控电脑上 Claude Code 的移动应用。解决程序员离开工位时无法处理紧急编程任务的痛点。

### 1.2 目标

| 目标 | 说明 |
|------|------|
| 实时性 | 流式输出延迟 < 500ms |
| 可靠性 | 消息发送成功率 > 99% |
| 安全性 | 加密传输 + 密码认证 |
| 易用性 | 简洁的移动端交互 |

### 1.3 约束条件

| 约束类型 | 描述 |
|----------|------|
| 技术约束 | Mac 开发机 + Cloudflare Tunnel |
| 用户约束 | 单用户（个人使用）|
| 网络约束 | 需要公网访问能力 |

## 2. 系统架构

### 2.1 系统上下文（C4 L1）

```
+------------------------------------------------------------------+
|                          外部环境                                  |
+------------------------------------------------------------------+
        |                                           |
        v                                           v
+----------------+                          +----------------+
|    开发者      |                          | Cloudflare     |
|   (手机端)     |                          | Tunnel         |
+----------------+                          +----------------+
        |                                           |
        | HTTPS/WSS                                 |
        v                                           v
+------------------------------------------------------------------+
|                                                                    |
|                     Phone Coder System                             |
|                                                                    |
|  +--------------------+         +--------------------+             |
|  |    Ionic App       |  WSS    |    Go Server       |             |
|  |    (手机端)         | <-----> |    (本地 Mac)       |             |
|  +--------------------+         +----------+---------+             |
|                                            |                       |
|                                            | stdin/stdout          |
|                                            v                       |
|                                 +--------------------+             |
|                                 |   Claude Code      |             |
|                                 |   (子进程)          |             |
|                                 +--------------------+             |
|                                                                    |
+------------------------------------------------------------------+
```

**说明**：
- 开发者通过手机端 App 与系统交互
- App 通过 Cloudflare Tunnel 建立 WSS 连接到本地 Go Server
- Go Server 管理 Claude Code 子进程，转发消息

### 2.2 容器图（C4 L2）

```
+------------------------------------------------------------------+
|                         Phone Coder                                |
+------------------------------------------------------------------+
|                                                                    |
|  +-----------------------+                                         |
|  |      Ionic App        |                                         |
|  |-----------------------|                                         |
|  | - 密码认证            |                                         |
|  | - 会话管理            |                                         |
|  | - 消息收发            |                                         |
|  | - Markdown 渲染       |                                         |
|  +-----------+-----------+                                         |
|              |                                                     |
|              | WSS (Cloudflare Tunnel)                             |
|              v                                                     |
|  +-----------------------+         +-----------------------+       |
|  |      Go Server        |         |       SQLite          |       |
|  |-----------------------| ------> |-----------------------|       |
|  | - WebSocket 路由      |         | - 会话持久化          |       |
|  | - 密码校验            |         | - 配置存储            |       |
|  | - 会话管理            |         +-----------------------+       |
|  | - 进程管理            |                                         |
|  +-----------+-----------+                                         |
|              |                                                     |
|              | stdin/stdout (子进程)                               |
|              v                                                     |
|  +-----------------------+                                         |
|  |     Claude Code       |                                         |
|  |-----------------------|                                         |
|  | - AI 编程助手         |                                         |
|  | - 代码生成/修改       |                                         |
|  +-----------------------+                                         |
|                                                                    |
+------------------------------------------------------------------+
```

| 容器 | 技术 | 职责 |
|------|------|------|
| Ionic App | Ionic + React + TypeScript | 移动端用户界面 |
| Go Server | Go + gorilla/websocket | WebSocket 服务、进程管理 |
| SQLite | SQLite | 会话持久化 |
| Claude Code | CLI | AI 编程助手 |

## 3. 技术选型

### 3.1 前端技术栈

| 类别 | 技术 | 版本 | 选型理由 |
|------|------|------|----------|
| 框架 | React | 18.x | 生态丰富、团队熟悉 |
| UI 库 | Ionic | 8.x | 跨平台、原生体验 |
| 移动端 | Capacitor | 6.x | 官方推荐、插件丰富 |
| 状态管理 | Zustand | 4.x | 轻量、简洁 |
| 构建工具 | Vite | 5.x | 快速构建 |
| 语言 | TypeScript | 5.x | 类型安全 |

### 3.2 后端技术栈

| 类别 | 技术 | 版本 | 选型理由 |
|------|------|------|----------|
| 语言 | Go | 1.21+ | 高性能、并发友好、单二进制部署 |
| WebSocket | gorilla/websocket | - | 成熟稳定 |
| 数据库 | SQLite | - | 轻量、无需独立服务 |
| 配置 | YAML | - | 简单易读 |

### 3.3 基础设施

| 类别 | 技术 | 说明 |
|------|------|------|
| 网络穿透 | Cloudflare Tunnel | HTTPS/WSS 加密 |
| 部署 | 本地 Mac | 单机部署 |
| 进程管理 | Go 子进程 | 管理 Claude Code |

## 4. 核心数据流

### 4.1 消息发送流程

```
+----------+     +------------------+     +----------+     +-------------+
|  App     |     | Cloudflare      |     | Go Server|     | Claude Code |
+----------+     +------------------+     +----------+     +-------------+
     |                   |                     |                 |
     | 1. message.send   |                     |                 |
     |------------------>|                     |                 |
     |                   | 2. WSS 转发         |                 |
     |                   |-------------------->|                 |
     |                   |                     | 3. 写入 stdin   |
     |                   |                     |---------------->|
     |                   |                     |                 |
     |                   |                     | 4. stdout 输出  |
     |                   |                     |<----------------|
     |                   | 5. message.stream   |                 |
     |                   |<--------------------|                 |
     | 6. 实时显示       |                     |                 |
     |<------------------|                     |                 |
     |                   |                     |                 |
     |                   | 7. message.done     |                 |
     |                   |<--------------------|                 |
     | 8. 完成状态       |                     |                 |
     |<------------------|                     |                 |
+----------+     +------------------+     +----------+     +-------------+
```

### 4.2 认证流程

```
+----------+     +------------------+     +----------+
|  App     |     | Cloudflare      |     | Go Server|
+----------+     +------------------+     +----------+
     |                   |                     |
     | 1. 建立 WSS 连接  |                     |
     |------------------>|-------------------->|
     |                   |                     |
     | 2. auth (password)|                     |
     |------------------>|-------------------->|
     |                   |                     | 3. 校验密码
     |                   |                     |
     |                   | 4. auth.result      |
     |                   |<--------------------|
     | 5. 认证结果       |                     |
     |<------------------|                     |
     |                   |                     |
     | (认证成功后可发送其他消息)              |
+----------+     +------------------+     +----------+
```

## 5. 非功能性需求

### 5.1 性能要求

| 指标 | 目标值 |
|------|--------|
| 流式输出延迟 | < 500ms |
| 端到端延迟 | < 2s |
| 消息发送成功率 | > 99% |

### 5.2 安全要求

| 安全措施 | 说明 |
|----------|------|
| 传输加密 | Cloudflare Tunnel 提供 HTTPS/WSS |
| 密码认证 | 每次连接验证密码 |
| 本地部署 | 代码不经第三方服务器 |

### 5.3 可用性要求

| 要求 | 说明 |
|------|------|
| 断线重连 | 自动重连 + 状态提示 |
| 错误提示 | 明确的用户提示 |
