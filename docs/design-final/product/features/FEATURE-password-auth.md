## 1. 功能概述

### 1.1 背景

Phone Coder 允许用户通过手机远程操控本地开发机上的 Claude Code。由于涉及代码执行权限，必须有认证机制防止未授权访问，保护开发环境安全。

### 1.2 目标

通过密码认证确保只有合法用户才能远程操控开发机上的 Claude Code，这是 Phone Coder 的安全基础功能。

### 1.3 范围

**包含**：
- 密码输入界面
- 密码验证
- 认证状态管理
- 密码本地保存（可选）

**不包含**：
- 多用户管理
- Token 认证（规划在 v0.2）
- 修改密码界面（通过配置文件修改）
- 双因素认证

## 4. 详细设计

### 4.1 业务规则

| 规则 | 说明 |
|------|------|
| 密码存储（服务端） | 存储在 config.yaml 文件中 |
| 密码存储（客户端） | 使用系统安全存储（Keychain/Keystore） |
| 认证时机 | 每次 WebSocket 连接建立后立即认证 |
| 失败处理 | 显示错误信息，清空密码框，允许重新输入 |
| 会话有效期 | 连接断开后需重新认证 |
| 连接超时 | 10s 内未收到响应则显示连接失败 |
| 重试限制 | 暂无限制，未来考虑添加 |

### 4.2 接口描述

#### 接口1：auth（客户端 → Server）

**功能说明**：发送密码进行认证

**请求格式**：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| type | String | 是 | 固定为 "auth" |
| password | String | 是 | 用户输入的密码 |

**示例**：
```json
{
  "type": "auth",
  "password": "my_secure_password"
}
```

#### 接口2：auth.result（Server → 客户端）

**功能说明**：返回认证结果

**响应格式**：

| 字段 | 类型 | 说明 |
|------|------|------|
| type | String | 固定为 "auth.result" |
| success | Boolean | 认证是否成功 |
| message | String | 失败时的错误信息 |

**成功示例**：
```json
{
  "type": "auth.result",
  "success": true
}
```

**失败示例**：
```json
{
  "type": "auth.result",
  "success": false,
  "message": "密码错误"
}
```

**错误码定义**：

| 错误场景 | success | message |
|----------|---------|---------|
| 密码正确 | true | - |
| 密码错误 | false | "密码错误" |
| 密码为空 | false | "请输入密码" |

### 4.3 状态流转

**认证状态**：

| 状态值 | 状态名称 | 说明 |
|--------|----------|------|
| idle | 空闲 | 等待用户输入 |
| connecting | 连接中 | 正在建立 WebSocket 连接 |
| authenticating | 认证中 | 已发送认证请求，等待响应 |
| authenticated | 已认证 | 认证成功 |
| failed | 失败 | 认证失败或连接失败 |

**状态流转图**：

```
+------------+   点击连接   +-------------+   连接成功   +--------------+
|    idle    | -----------> | connecting  | -----------> | authenticating|
+------------+              +-------------+              +--------------+
      ^                           |                            |
      |                           | 连接失败                    |
      |                           v                       +----+----+
      |                     +------------+               |          |
      +-------------------- |   failed   | <-------- 认证失败    认证成功
      |      重试           +------------+               |          |
      |                                                  |          v
      |                                                  |   +-------------+
      +--------------------------------------------------+   | authenticated|
                                                             +-------------+
                                                                    |
                                                                    v
                                                             进入首页
```

### 4.4 安全考虑

| 安全措施 | 说明 |
|----------|------|
| 传输加密 | 通过 Cloudflare Tunnel 的 HTTPS/WSS 加密传输 |
| 密码不明文存储 | 服务端密码建议使用 bcrypt 哈希存储（v0.2 实现） |
| 客户端安全存储 | 使用 iOS Keychain / Android Keystore |
| 防暴力破解 | 未来考虑添加失败次数限制和延迟机制 |

## 5. 验收标准

| 场景 | 前置条件 | 操作步骤 | 预期结果 |
|------|----------|----------|----------|
| 正确密码 | Server 运行中 | 1. 输入正确密码 2. 点击连接 | 进入首页（会话列表） |
| 错误密码 | Server 运行中 | 1. 输入错误密码 2. 点击连接 | 显示"密码错误"，清空密码框 |
| 空密码 | - | 1. 不输入密码 | 连接按钮置灰，无法点击 |
| 记住密码 | 勾选"记住密码" | 1. 输入密码 2. 连接成功 3. 重启 App | 密码自动填充 |
| 连接超时 | Server 不可达 | 1. 点击连接 | 10s 后显示"无法连接到服务器" |
| 显示密码 | 已输入密码 | 1. 点击眼睛图标 | 密码明文显示 |
