## 1. 功能概述

### 1.1 背景

开发者通常同时在多个项目上工作，需要能够管理多个 Claude Code 会话，每个会话对应不同的项目目录。这是使用 Phone Coder 的入口功能。

### 1.2 目标

提供完整的会话管理能力：
- 查看所有会话列表
- 创建新会话（指定工作目录）
- 切换会话
- 关闭/删除会话

### 1.3 范围

**包含**：
- 会话列表展示
- 创建新会话
- 切换会话
- 删除/关闭会话
- 会话状态显示

**不包含**：
- 会话内容搜索
- 会话导出
- 会话分组

- 反馈形式：弹出目录选择弹窗
- 特殊说明：预设目录从 Server config.yaml 读取

## 4. 详细设计

### 4.1 业务规则

| 规则 | 说明 |
|------|------|
| 预设目录 | 从 config.yaml 的 workdirs 列表读取，不支持手动输入 |
| 会话状态 | running（执行中）、idle（空闲） |
| 会话持久化 | 会话信息存储在服务端 SQLite，客户端不缓存 |
| 会话排序 | 按最近使用时间倒序，running 状态置顶 |
| 状态显示 | running（绿点）、idle（灰点） |
| 删除规则 | 删除会话同时关闭 Claude Code 进程 |

### 4.2 接口描述

#### 接口1：session.list（客户端 → Server）

**功能说明**：获取所有会话列表

**请求格式**：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| type | String | 是 | 固定为 "session.list" |

**响应格式**：

| 字段 | 类型 | 说明 |
|------|------|------|
| type | String | 固定为 "session.list" |
| sessions | Array | 会话列表 |
| sessions[].id | String | 会话 ID |
| sessions[].name | String | 项目名（目录名） |
| sessions[].workDir | String | 工作目录完整路径 |
| sessions[].status | String | 状态：running/idle |
| sessions[].updatedAt | String | 最后更新时间（ISO 8601） |
| workdirs | Array | 可用的预设目录列表 |

**示例**：
```json
{
  "type": "session.list",
  "sessions": [
    {
      "id": "sess_123",
      "name": "my-project",
      "workDir": "/Users/xxx/workspace/my-project",
      "status": "running",
      "updatedAt": "2025-12-30T10:30:00Z"
    }
  ],
  "workdirs": [
    "/Users/xxx/workspace/my-project",
    "/Users/xxx/workspace/api-server"
  ]
}
```

#### 接口2：session.create（客户端 → Server）

**功能说明**：创建新会话

**请求格式**：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| type | String | 是 | 固定为 "session.create" |
| workDir | String | 是 | 工作目录路径（必须是预设目录之一） |

**响应格式**：

| 字段 | 类型 | 说明 |
|------|------|------|
| type | String | 固定为 "session.created" |
| sessionId | String | 新会话 ID |
| name | String | 项目名 |
| workDir | String | 工作目录 |

**错误处理**：

| 错误码 | 说明 | 用户提示 |
|--------|------|----------|
| DIR_NOT_FOUND | 目录不存在 | "目录不存在" |
| DIR_NOT_ALLOWED | 目录不在预设列表 | "该目录不在允许列表中" |
| PERMISSION_DENIED | 权限不足 | "无权限访问该目录" |

#### 接口3：session.delete（客户端 → Server）

**功能说明**：删除会话

**请求格式**：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| type | String | 是 | 固定为 "session.delete" |
| sessionId | String | 是 | 会话 ID |

**响应格式**：

| 字段 | 类型 | 说明 |
|------|------|------|
| type | String | 固定为 "session.deleted" |
| sessionId | String | 被删除的会话 ID |

**错误处理**：

| 错误码 | 说明 | 用户提示 |
|--------|------|----------|
| SESSION_NOT_FOUND | 会话不存在 | "会话不存在" |

### 4.3 状态流转

**会话状态**：

| 状态值 | 状态名称 | 说明 |
|--------|----------|------|
| running | 运行中 | Claude Code 正在执行任务 |
| idle | 空闲 | Claude Code 等待输入 |

**状态流转图**：

```
                  创建会话
                     |
                     v
+------------+   发送消息   +------------+
|    idle    | -----------> |  running   |
+------------+ <----------- +------------+
                 任务完成

+------------+
|  (删除)    |  <- 任意状态均可删除
+------------+
```

## 5. 验收标准

| 场景 | 前置条件 | 操作步骤 | 预期结果 |
|------|----------|----------|----------|
| 查看列表 | 有历史会话 | 1. 打开 App 2. 完成认证 | 显示所有会话，按时间排序，running 置顶 |
| 创建会话 | 已连接 Server | 1. 点击新建 2. 选择目录 3. 确认 | 创建成功，进入聊天页 |
| 删除会话 | 有会话存在 | 1. 左滑会话 2. 点击删除 3. 确认 | 会话从列表消失 |
| 切换会话 | 有多个会话 | 1. 返回首页 2. 点击另一会话 | 进入对应聊天页 |
| 删除运行中会话 | 会话状态为 running | 1. 左滑 2. 点击删除 | 先停止进程，再删除会话 |
