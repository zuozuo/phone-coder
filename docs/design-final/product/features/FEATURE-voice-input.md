## 1. 功能概述

### 1.1 背景

在移动场景下（如通勤、步行），手机打字不方便，需要通过语音输入来发送消息。语音输入可以显著提升移动端的操作效率。

### 1.2 目标

提供语音输入能力，将语音转为文字后发送给 Claude Code。

### 1.3 范围

**包含**：
- 语音录制
- 语音转文字
- 编辑识别结果
- 发送

**不包含**：
- 语音直接发送（保留原始录音）
- 多语言混合识别
- 实时转写（边说边显示）
- 语音唤醒

### 3.4 关键交互说明

**交互点1**：开始录音

- 特殊说明：首次使用需请求麦克风权限

- 反馈形式：显示"识别中..."，然后结果填入输入框

- 触发方式：点击取消按钮
- 反馈形式：返回正常输入状态
- 特殊说明：录音内容丢弃

## 4. 详细设计

### 4.1 业务规则

| 规则 | 说明 |
|------|------|
| 录音时长 | 最短 1 秒，最长 60 秒 |
| 识别服务 | 使用系统原生语音识别（iOS Speech Framework / Android SpeechRecognizer） |
| 结果处理 | 识别结果填入输入框，用户可编辑 |
| 权限处理 | 无权限时引导用户到设置页授权 |
| 网络要求 | 语音识别需要网络连接（在线识别） |

### 4.2 技术方案

**iOS**：
- AVAudioSession（录音）
- SFSpeechRecognizer（语音识别）

**Android**：
- MediaRecorder（录音）
- SpeechRecognizer（语音识别）

**Capacitor 插件**：
- @capacitor-community/speech-recognition

### 4.3 状态流转

**语音输入状态**：

| 状态值 | 状态名称 | 说明 |
|--------|----------|------|
| idle | 空闲 | 显示麦克风按钮 |
| recording | 录音中 | 显示录音界面 |
| recognizing | 识别中 | 显示识别进度 |
| done | 完成 | 结果已填入输入框 |
| error | 错误 | 显示错误提示 |

**状态流转图**：

```
+------------+   点击麦克风   +------------+   点击完成   +-------------+
|    idle    | ------------> | recording  | -----------> | recognizing |
+------------+               +------------+              +-------------+
      ^                           |                            |
      |                           | 点击取消                    |
      |                           v                       +----+----+
      +---------------------------+                      |          |
      |                                               成功        失败
      |                                                  |          |
      |                                                  v          v
      |                                           +--------+  +--------+
      +------------------------------------------ |  done  |  | error  |
                                                  +--------+  +--------+
```

## 5. 验收标准

| 场景 | 前置条件 | 操作步骤 | 预期结果 |
|------|----------|----------|----------|
| 正常录音 | 有麦克风权限 | 1. 点击麦克风 2. 说话 3. 点击完成 | 识别结果显示在输入框 |
| 编辑发送 | 已完成识别 | 1. 编辑文字 2. 点击发送 | 编辑后的内容被发送 |
| 取消录音 | 录音中 | 1. 点击取消 | 返回正常状态，录音丢弃 |
| 无权限 | 未授权麦克风 | 1. 点击麦克风 | 显示权限请求或设置引导 |
| 识别失败 | 网络异常 | 1. 录音 2. 完成 | 显示"识别失败"，提供重试 |
| 超时录音 | 录音超过 60s | 1. 持续录音 | 60s 后自动停止，开始识别 |
