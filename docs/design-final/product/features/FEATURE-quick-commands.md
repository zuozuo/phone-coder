## 1. 功能概述

### 1.1 背景

在与 Claude Code 交互时，有些指令经常使用（如"继续"、"取消"、"/help"），每次手动输入效率低。在移动端打字更加不便，快捷指令可以显著提升操作效率。

### 1.2 目标

提供快捷指令按钮，一键发送常用命令。

### 1.3 范围

**包含**：
- 预设快捷指令
- 一键发送
- 展开更多指令

**不包含**：
- 自定义快捷指令（规划在 v0.3）
- 指令参数输入
- 指令组合/宏

## 3. 交互设计

### 3.1 页面清单

| 页面 | 入口 | 功能说明 |
|------|------|----------|
| 聊天页（快捷指令栏） | 输入区上方 | 显示快捷指令按钮 |

### 3.2 交互流程

```
+------------------+
|  点击快捷指令    |
+------------------+
        |
        v
+------------------+     否      +------------------+
|  会话空闲？      | ----------> |  提示请等待      |
+------------------+             +------------------+
        | 是
        v
+------------------+
|  发送对应文本    |
+------------------+
        |
        v
+------------------+
|  等待 Claude 响应 |
+------------------+
```

### 3.3 界面线框图

**正常状态（收起）**：
```
+------------------------------------------+
|                                          |
|            (消息列表区域)                 |
|                                          |
+------------------------------------------+
|  [继续] [取消] [/help] [/status] [更多▼] |  <- 快捷指令栏
+------------------------------------------+
|  +----------------------------+  🎤  ➤  |
|  |  输入消息...               |         |
|  +----------------------------+         |
+------------------------------------------+
```

**展开状态**：
```
+------------------------------------------+
|                                          |
|            (消息列表区域)                 |
|                                          |
+------------------------------------------+
|  [继续] [取消] [/help] [/status] [更多▲] |
+------------------------------------------+
|  [/compact] [/cost] [/clear] [/doctor]  |  <- 第二行
+------------------------------------------+
|  +----------------------------+  🎤  ➤  |
|  +----------------------------+         |
+------------------------------------------+
```

**会话运行中状态**：
```
+------------------------------------------+
|  [继续] [取消] [/help] [/status] [更多▼] |  <- 按钮置灰
+------------------------------------------+
```

### 3.4 关键交互说明

**交互点1**：点击快捷指令
- 触发方式：点击按钮
- 反馈形式：直接发送对应文本，等同于手动输入后发送
- 特殊说明：不需要确认，立即发送

**交互点2**：展开更多
- 触发方式：点击"更多"按钮
- 反馈形式：展开第二行快捷指令
- 特殊说明：再次点击收起

**交互点3**：运行中状态
- 触发方式：会话状态为 running
- 反馈形式：快捷指令按钮置灰，不可点击
- 特殊说明：等待任务完成后恢复

## 4. 详细设计

### 4.1 业务规则

| 规则 | 说明 |
|------|------|
| 发送行为 | 点击即发送，等同于输入文本后点击发送 |
| 状态限制 | 会话空闲（idle）时才能发送 |
| 展开状态 | 默认收起，用户展开后保持展开直到切换会话 |
| 按钮顺序 | 按使用频率排序，常用在前 |

### 4.2 快捷指令列表

**第一行（常用）**：

| 按钮 | 发送内容 | 说明 |
|------|----------|------|
| 继续 | 继续 | 让 Claude 继续之前的任务 |
| 取消 | 取消 | 取消当前操作 |
| /help | /help | 显示帮助信息 |
| /status | /status | 显示当前状态 |

**第二行（更多）**：

| 按钮 | 发送内容 | 说明 |
|------|----------|------|
| /compact | /compact | 压缩对话历史 |
| /cost | /cost | 显示 token 消耗 |
| /clear | /clear | 清空对话历史 |
| /doctor | /doctor | 诊断问题 |

### 4.3 状态流转

**快捷指令栏状态**：

| 状态值 | 状态名称 | 说明 |
|--------|----------|------|
| enabled | 可用 | 会话空闲，按钮可点击 |
| disabled | 禁用 | 会话运行中，按钮置灰 |
| collapsed | 收起 | 只显示第一行 |
| expanded | 展开 | 显示两行 |

## 5. 验收标准

| 场景 | 前置条件 | 操作步骤 | 预期结果 |
|------|----------|----------|----------|
| 发送快捷指令 | 会话空闲 | 1. 点击 [继续] | 发送"继续"，Claude 响应 |
| 展开更多 | 正常状态 | 1. 点击 [更多▼] | 显示第二行指令 |
| 收起更多 | 已展开 | 1. 点击 [更多▲] | 收起第二行 |
| 运行中禁用 | 会话运行中 | 1. 观察按钮 | 所有按钮置灰不可点击 |
| 发送 /help | 会话空闲 | 1. 点击 [/help] | 发送"/help"，显示帮助信息 |

## 7. 未来规划（v0.3）

### 7.1 自定义快捷指令

允许用户添加、编辑、删除快捷指令：

```
+------------------------------------------+
|           管理快捷指令                ✕   |
+------------------------------------------+
|                                          |
|  +------------------------------------+  |
|  | 继续                          ✏️ 🗑 |  |
|  +------------------------------------+  |
|  | 取消                          ✏️ 🗑 |  |
|  +------------------------------------+  |
|  | /help                         ✏️ 🗑 |  |
|  +------------------------------------+  |
|                                          |
|         [ + 添加指令 ]                    |
|                                          |
+------------------------------------------+
```

### 7.2 指令分组

支持按类别分组指令（如：常用、调试、Git 等）。
