## 1. 我们要解决什么问题？

程序员在离开电脑时无法继续编程任务。当出现紧急 bug 或需要快速迭代时，只能等到回到工位才能处理。Phone Coder 让程序员可以在手机上远程操控电脑上的 Claude Code，实现真正的移动编程。

---

## 2. 为谁解决？

### 2.1 目标用户画像

| 维度 | 描述 |
|------|------|
| 主要用户 | 需要 on-call 响应的后端/全栈程序员 |
| 使用场景 | 通勤途中、休息时接到紧急修复需求 |
| 技术背景 | 熟悉 CLI 工具，有使用 Claude Code 经验 |
| 设备环境 | Mac 开发机 + iPhone/Android 手机 |

### 2.2 用户痛点

| 痛点 | 严重程度 | 现有解决方案的不足 |
|------|----------|-------------------|
| 离开工位无法处理紧急 bug | 高 | SSH 操作体验差，无 AI 辅助 |
| 手机打字效率低 | 中 | 语音输入可缓解 |
| 无法查看长时间任务的执行结果 | 高 | 只能等回到电脑前 |

## 4. 产品架构

### 4.1 系统分层

```
+------------------------------------------+
|               用户层                      |
|  +------------------------------------+  |
|  |         Ionic App (手机端)         |  |
|  |  - 密码认证                        |  |
|  |  - WebSocket 通信                  |  |
|  |  - Markdown 渲染                   |  |
|  +------------------------------------+  |
+------------------------------------------+
                    |
                    | HTTPS/WSS (Cloudflare Tunnel)
                    v
+------------------------------------------+
|               服务层                      |
|  +------------------------------------+  |
|  |          Go Server (本地 Mac)      |  |
|  |  - 密码校验                        |  |
|  |  - 会话管理                        |  |
|  |  - 进程管理                        |  |
|  |  - WebSocket 路由                  |  |
|  +------------------------------------+  |
+------------------------------------------+
                    |
                    | stdin/stdout (子进程)
                    v
+------------------------------------------+
|               CLI 层                      |
|  +------------------------------------+  |
|  |           Claude Code              |  |
|  +------------------------------------+  |
+------------------------------------------+
```

### 4.2 数据流说明

```
┌─────────────────┐     HTTPS/WSS      ┌─────────────────┐
│   Ionic App     │ ←───────────────→  │   Go Server     │
│   (手机端)       │   Cloudflare       │   (本地 Mac)     │
│                 │     Tunnel         │                 │
└─────────────────┘                    └────────┬────────┘
                                               │ stdin/stdout
                                      ┌────────┴────────┐
                                      │   Claude Code   │
                                      │   (子进程)       │
                                      └─────────────────┘
```

1. 手机端通过 Cloudflare Tunnel 建立 WSS 连接
2. 认证通过后，指令通过 WebSocket 发送到 Go Server
3. Go Server 将指令写入 Claude Code stdin
4. Claude Code stdout 通过 WebSocket 流式推送到手机端

## 6. 非功能性需求

| 类型 | 要求 | 说明 |
|------|------|------|
| 安全性 | 所有通信必须加密（HTTPS/WSS） | 通过 Cloudflare Tunnel 实现 |
| 安全性 | 密码认证 | 每次连接需验证密码 |
| 隐私 | 代码内容不经过第三方服务器存储 | 数据仅在本机和手机间传输 |
| 可用性 | 服务中断时客户端应有明确提示 | 断线重连 + 状态提示 |
| 性能 | 流式输出延迟 < 500ms | 实时性要求 |
| 兼容性 | iOS 15+, Android 10+ | 覆盖主流设备 |

## 8. 术语表

| 术语 | 定义 |
|------|------|
| 会话 (Session) | 一个独立的 Claude Code 进程实例，对应一个工作目录 |
| 流式输出 (Stream) | Claude Code 实时生成的输出内容 |
| 工作目录 (WorkDir) | Claude Code 运行的项目目录 |
